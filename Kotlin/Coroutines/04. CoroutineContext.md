# CoroutineContext

### Что такое CoroutineContext?
`CoroutineContext` - это неизменяемый набор элементов, каждый из которых отвечает за определенную часть окружения корутины. <br>Каждый элемент имеет уникальный ключ `Key`, по которому его можно получить, заменить или удалить.

### Элементы контекста?
| **Элемент**                   | **Описание**                                                    |
|-------------------------------|-----------------------------------------------------------------|
| **Job**                       | Жизненный цикл корутины, отмена, родительско-дочерняя связь     |
| **CoroutineDispatcher**       | На каком потоке (или пулах потоков) будет выполняться корутина  |
| **CoroutineName**             | Имя корутины для отладки                                        |
| **CoroutineExceptionHandler** | Обработка необработанных исключений                             |
| **ThreadContextElement**      | Перенос данных в контекст потока                                |
| **ContinuationInterceptor**   | Перехват continuation; обычно реализуется Dispatcher            |

### Свой элемент контекста?
- Необходимо наследовать класс от абстрактного класса AbstractCoroutineContextElement(key: Key<*>)
- И унаследовать его объект-компаньен от интерфейса CoroutineContext.Key

``` kotlin
class MyContextElement : AbstractCoroutineContextElement(key = MyContextElement) {

    companion object Key : CoroutineContext.Key<MyContextElement>
}
```

### Примеры кода
``` kotlin
// Интерфейс CoroutineContext
public interface CoroutineContext {
    public operator fun get(key: Key<E>): E?
    public fun <R> fold(initial: R, operation: (R, Element) -> R): R
    public operator fun plus(context: CoroutineContext): CoroutineContext
    public fun minusKey(key: Key<*>): CoroutineContext
    public interface Key<E : Element>
    public interface Element : CoroutineContext {
        public val key: Key<*>
        // дефолтные реализации get/fold/plus/minusKey
    }
}

// Создание CoroutineContext объединением его элементов
val context =
    Job() +
    Dispatchers.IO +
    CoroutineName("Download") +
    CoroutineExceptionHandler { _, error ->
        println(error)
    }
```
