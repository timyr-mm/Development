# Скоуп - CoroutineScope


### Что такое скоуп / CoroutineScope?
`CoroutineScope` - это интерфейс являющийся контейнером в рамках которого живет корутина и позволяет управлять ее жизненным циклом и задавать контекст.
Скоуп необходим для реализации структурированной конкурентности, согласно которой, асинхронные задачи должны быть инкапсулированы в логические группы.
Это позволяет контролировать их жизненный цикл: если скоуп отменяется или завершается, все корутины, запущенные в нем, автоматически прекращают свое выполнение.

### Как устроен CoroutineScope?
`CoroutineScope` - это практически обертка над `CoroutineContex`. В нем нет: собственного состояния и жизненного цикла, механизма запуска и отмены корутины. <br/>Он больше нужен для разделения ответственности: `CoroutineContex` - отвечает за окружение выполнения корутины. `CoroutineScope` - за удобную организацию и границы конкурентности.

### Получить/Создать скоуп
| **Скоупы**                          | **Описание**                                                                                                                                                                                                                                                                                                                                                                                                                |
|-------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **viewModelScope**                  | Привязан к жизненному циклу `ViewModel`. Автоматически отменяется когда `ViewModel` очищается (`onCleared()`). <br/>Использует `SupervisorJob()` и работает на `Dispatchers.Main`                                                                                                                                                                                                                                           |
| **lifecycleScope**                  | Привязан к `Lifecycle` конкретного Android компонента (Activity, Fragment, View ...). Автоматически отменяется, когда `Lifecycle` переходит в состояние `DESTROYED`. <br/>Использует `SupervisorJob()` и работает на `Dispatchers.Main`                                                                                                                                                                                     |
| **CoroutineScope(context = Job())** | Самостоятельное создание `CoroutineScope` с последующим управлением его жизненного цикла. <br/>`CoroutineScope(context)` - это фабричная функция, под капотом создается `ContextScope`. Если в параметре `context` не был передан `Job`, функция его добавит сама. <br/>Важно самому управлять жизненным циклом скоупа! Если пользователь вышел с экрана, а в репозитории были активные корутины с запросами, их нужно отменить. |
| **GlobalScope**                     | Глобальный `CoroutineScope`, который не привязан к жизненному циклу какого-либо объекта и не имеет родительского `Job`. Из-за отсутсвия `Job`, скоуп не отменить `cancel()`, по этому каждая его корутина будет считаться корневой (их можно отменять). Стоит использовать только тогда, когда жизненный цикл намеренно не должен зависеть от конкретного экрана или компонента.                                            |

### Примеры кода
``` kotlin
public interface CoroutineScope {
    public val coroutineContext: CoroutineContext
}

public fun CoroutineScope(context: CoroutineContext): CoroutineScope =
    ContextScope(if (context[Job] != null) context else context + Job())

public val CoroutineScope.isActive: Boolean
    get() = coroutineContext[Job]?.isActive ?: true
    
public fun CoroutineScope.cancel(cause: CancellationException? = null) {
    val job = coroutineContext[Job] ?: error("Scope cannot be cancelled because it does not have a job: $this")
    job.cancel(cause)
}
```
