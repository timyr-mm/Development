# Job, Deferred, Билдеры


### Что такое Job?
Job — Это дескриптор (управляющий объект) корутины, который позволяет управлять её жизненным циклом (через сам интерфейс Job): ожидать завершения, отменять, проверять состояние.

### Какие бывают состояния у Job?

| **Состояние**                  | **isActive** | **isCompleted** | **isCancelled** |
|--------------------------------|--------------|-----------------|-----------------|
| New (optional initial state)   | false        | false           | false           |
| Active (default initial state) | true         | false           | false           |
| Completing (transient state)   | true         | false           | false           |
| Cancelling (transient state)   | false        | false           | true            |
| Cancelled (final state)        | false        | true            | true            |
| Completed (final state)        | false        | true            | false           |

**Интерфейс Job**
``` kotlin
public interface Job : CoroutineContext.Element {
    public companion object Key : CoroutineContext.Key<Job>

    @ExperimentalCoroutinesApi
    public val parent: Job?

    public val isActive: Boolean

    public val isCompleted: Boolean

    public val isCancelled: Boolean

    public fun start(): Boolean
	
    public fun cancel(cause: CancellationException? = null)

    public val children: Sequence<Job>

    public suspend fun join()
}
```

### Что такое Deferred?
Deferred — Наследник Job, который расширяет его для возможности получения результата работы корутины через функцию `await()`. Корутина выполняется сразу, даже если функция `await()` не была вызвана.

**Интерфейс Deferred<T> : Job**
``` kotlin
public interface Deferred<out T> : Job {
    public suspend fun await(): T

    public val onAwait: SelectClause1<T>

    @ExperimentalCoroutinesApi
    public fun getCompleted(): T

    @ExperimentalCoroutinesApi
    public fun getCompletionExceptionOrNull(): Throwable?
}
```

### Что такое билдер?
Билдер корутины — это функция, создающая и запускающая корутину на основе переданного блока кода.

### Какие бывают билдеры?

| **Билдер**          | **Описание**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Что возвращает  | Когда использовать                                                                                                                            |
|---------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| **launch**          | Создает и запускает новую корутину и возвращает `Job`, через который можно управлять её жизненным циклом. <br/> <br/> Параметром `CoroutineStart` можно настроить Lazy запуск (через функцию `Job.start()`)                                                                                                                                                                                                                                                                                                                               | Job             | Асинхронная работа, без получения результата (Загрузка данных, обновление UI, фоновая работа)                                                 |
| **async**           | Создает и запускает новую корутину и возвращает `Deferred<T>` (наследник `Job`), позволяющий получить результат её выполнения. <br/> <br/> Корутина выполняется сразу, даже если `Deferred.await()` не был вызван.                                                                                                                                                                                                                                                                                                                        | Deferred<T>     | Когда нужно получить результат асинхронной операции (Особенно когда есть несколько независимых операций)                                      |
| **runBlocking**     | Создает и запускает корутину блокируя вызывающий поток до полного завершения её выполнения. <br/> <br/> Это особенный билдер: он позволяет вызвать suspend-код из обычного, не suspend-кода.                                                                                                                                                                                                                                                                                                                                              | T               | Точка входа в консольные приложения. Тестирование (уже есть `runTest {}`)                                                                     |
| **withContext**     | `suspend`-функция, которая выполняет блок кода в указанном `CoroutineContext`, приостанавливая вызывающую корутину до получения результата. <br/> <br/> Её основная задача — переключение контекста выполнения, например диспетчера. <br/> <br/> Создаётся новая дочерняя область выполнения с контекстом, полученным объединением текущего контекста и переданного context. <br/> <br/> `withContext` нужен не для запуска независимой фоновой задачи, а для выполнения части текущей работы в другом контексте с получением результата. | T               | Когда нужно выполнить определённую операцию в другом контексте. Например: Получить данные из сети на `IO` потоке                              |
| **coroutineScope**  | `suspend`-функция, которая создаёт новую область структурированной конкуррентности (Скоуп) внутри текущей корутины и приостанавливает вызывающую корутину до завершения блока и всех его дочерних корутин. <br/> <br/> `coroutineScope` позволяет объединить несколько корутин в одну операцию, гарантируя, что они не останутся работать после выхода из этой области.                                                                                                                                                                   | T               | Когда нужно сгруппировать несколько дочерних корутин в одну логическую операцию и гарантировать, что все они завершатся до выхода из области. |
| **supervisorScope** | `suspend`-функция, которая создаёт область структурированной конкуррентности (Скоуп) с супервизорной иерархией, в которой ошибка одной дочерней корутины не отменяет остальные дочерние корутины. <br/> <br/> `supervisorScope` изолирует ошибки дочерних корутин, но не ошибки самого блока `supervisorScope`. Если исключение выбрасывается непосредственно из блока, область отменяет своих детей.                                                                                                                                             | T               | Когда несколько независимых операций выполняются одновременно и сбой одной из них не должен останавливать остальные.                          |

### Примеры кода
**launch**
``` kotlin
fun CoroutineScope.launch(
    context: CoroutineContext = EmptyCoroutineContext,
    start: CoroutineStart = CoroutineStart.DEFAULT,
    block: suspend CoroutineScope.() -> Unit
): Job

val job = CoroutineScope(Dispatchers.IO).launch {
    delay(1000)
    println("File downloaded")
}
```

**async**
``` kotlin
fun CoroutineScope.async(
    context: CoroutineContext = EmptyCoroutineContext,
    start: CoroutineStart = CoroutineStart.DEFAULT,
    block: suspend CoroutineScope.() -> T
): Deferred<T>

val deferred = CoroutineScope(Dispatchers.IO).async {
    delay(1000)
    "Downloaded data"
}

val result = deferred.await()
```

**runBlocking**
``` kotlin
fun <T> runBlocking(
    context: CoroutineContext = EmptyCoroutineContext,
    block: suspend CoroutineScope.() -> T
): T

fun main() {
    val result = runBlocking {
        delay(1000)
        "Hello"
    }

    println(result)
}
```

**withContext**
``` kotlin
suspend fun <T> withContext(
    context: CoroutineContext,
    block: suspend CoroutineScope.() -> T
): T

viewModelScope.launch {
    val result = withContext(Dispatchers.IO) {
        repository.loadData()
    }

    println(result)
}
```

**coroutineScope**
``` kotlin
suspend fun <T> coroutineScope(
    block: suspend CoroutineScope.() -> T
): T

suspend fun loadData(): String = coroutineScope {
    val user = async {
        repository.getUser()
    }

    val products = async {
        repository.getProducts()
    }

    return "${user.await()} ${products.await()}"
}
```

**supervisorScope**
``` kotlin
suspend fun <T> supervisorScope(
    block: suspend CoroutineScope.() -> T
): T

suspend fun loadData() = supervisorScope {
    val user = async {
        loadUser()
    }

    val products = async {
        loadProducts()
    }

    // Обрабатываем ошибки независимо
    val userResult = runCatching {
        user.await()
    }

    val productsResult = runCatching {
        products.await()
    }
    
    return "$userResult $productsResult"
}
```
